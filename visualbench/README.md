# mjj visualbench

This is the visual feedback loop for multimodal coding runs. The gallery is
generated by `mjj`, captured at deterministic URLs, checked for runtime errors,
and scored for obvious blank/flat/clipped regressions. The numeric scores are
health signals, not a substitute for looking at the images.

```bash
cd visualbench
npm install
npm test
npm run capture
uv run --project .. python score.py
```

Screenshots and JSON reports land in ignored `output/`. `capture.mjs` uses the
Playwright browser cache when one is already installed; otherwise run
`npx playwright install chromium` once. `PLAYWRIGHT_CHROMIUM_EXECUTABLE` can
point at a system Chromium.

The current cases cover a procedural Three.js water scene, four visually
distinct image-to-image shaders, and a phone viewport. Gallery pages expose
`window.__VISUALBENCH_READY__` and accept `motion=0&time=N` so screenshots are
repeatable.

To compare models or providers, run the prompts in `cases.json` into a new
gallery directory with `mjj exec --provider … --image …`, add deterministic
cases, capture them, and review both screenshots and the report. Publish losses
alongside wins; a smaller or faster response is only better when the rendered
result remains good.
